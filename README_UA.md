# NFS Save Lab NX v0.7

**Три постери вже вшиті безпосередньо в .nro**: Most Wanted, Underground 2, Carbon. Тепер достатньо **одного** файлу:

`sdmc:/switch/nfs_save_lab_nx.nro`

Папка `/switch/NFS_Save_Lab_NX/posters/` від попередньої v0.6 більше **не потрібна**. Зображення вбудовуються під час GitHub Actions/devkitA64-збірки із даних у `assets/posters_embedded.json`. Для економії обсягу постери стиснуті до піксельного 80×100, 32 кольорів із масштабуванням без розмиття.

## Перевірені можливості

**Edit Cash (MC02) для Most Wanted Xbox 360**: сума 0–999 999 999, автоматичне зчитування поточного балансу, перевірка сигнатури/розміру/4 контрольних сум, резервна копія та перерахунок MD5 + 3 EA CRC32. Алгоритм уже пройшов реальний тест у грі з успішною зміною коштів. Перед кожним редагуванням **повністю закрий гру й зроби незалежну копію активного сейву**.

**Bounty Info (MC02)** — тепер програма вміє **зчитувати реальний поточний рейтинг** у Most Wanted, шукаючи унікальний 12-байтовий маркер запису, а не одну фіксовану адресу. На двох наданих сейвах значення **31 550** було за `0x010E`, а **45 150** — за `0x015A`; у кожному файлі маркер був унікальний, усі контрольні суми справні. Режим поки **тільки читання**. Змінювати рейтинг у грі ми зможемо дозволити після окремого успішного тесту модифікованого Bounty-сейву на Switch.

**Heat** залишається лише діагностикою. Underground 2 і Carbon поки мають браузер файлів і сканування, без підтвердженого редагування.

## Як перевірити Bounty

Закрий гру, запусти NFS Save Lab NX → Most Wanted → активний `[LIVE]` сейв → **BOUNTY INFO (MC02)**. Програма повинна показати його рейтинг та фактичний зсув запису. Для невідомих форматів або пошкоджених файлів показуватиме помилку і не записуватиме нічого.
