# NFS Save Lab NX — редактор збережень для Nintendo Switch

**Актуальна версія: v0.16.** Домашня програма (homebrew) для редагування збережень фанатських портів **Need for Speed: Most Wanted (2005), Underground 2 та Carbon** на Nintendo Switch.

[🇺🇦 Українська](README_UA.md) · [🇬🇧 English](README.md)

## Можливості

| Гра | Гроші (Cash) | Рейтинг (Bounty) |
|---|---|---|
| **Most Wanted (2005)** | ✅ | ✅ |
| **Underground 2** | ✅ | — |
| **Carbon** | ✅ | — |

- Можна встановити **власну суму грошей** в усіх трьох іграх.
- Для **Most Wanted** доступне редагування накопиченого Bounty з урахуванням автомобілів у гаражі та історії проданих машин. Якщо машин кілька, активний запис вибирається кнопками **L/R**.
- Програма автоматично знаходить кар’єри, перевіряє формат і контрольні підписи перед редагуванням.
- **Перед кожним записом створюється перевірена резервна копія** `.nfslab.bakN`. Після зміни файл перевіряється повторно.
- У повній HD-збірці є три піксельні постери та власна піксельна іконка для Homebrew Menu.

**Усі зазначені функції підтверджено в грі на Nintendo Switch.** Це не гарантує сумісності з кожним майбутнім портом або модифікованим сейвом. Програма призначена для конкретних фанатських Switch-портів, **не для PC-версій**.

## Де завантажити

Перейдіть у розділ **[GitHub Releases](https://github.com/koren699/NFS-Save-Lab-NX/releases)** і, після публікації релізу, завантажте файл **`nfs_save_lab_nx.nro` (Full HD)** або ZIP із програмою.

> Повний файл **Full HD** містить якісні постери та нашу іконку. Звичайний автоматичний артефакт з GitHub Actions може мати спрощену графіку.

## Як встановити та користуватися

1. Скопіюйте `nfs_save_lab_nx.nro` у папку `sdmc:/switch/` на microSD.
2. **Повністю закрийте гру.** Перед першим редагуванням зробіть незалежну копію **всієї папки збережень** поза робочою папкою гри.
3. Відкрийте Homebrew Menu, запустіть **NFS Save Lab NX** і виберіть постер потрібної гри.
4. Виберіть збереження (якщо їх кілька) та функцію **Edit Cash** або **Edit Bounty** для Most Wanted.
5. Стрілками виставте потрібне значення, натисніть **A**.
6. Для остаточного запису затисніть **ZL + ZR** і натисніть **A**.
7. Запустіть гру, перевірте баланс або рейтинг. Зберігайте оригінальну резервну копію до перевірки.

## Технічна інформація

- **Most Wanted:** Xbox 360 MC02, MD5 і контрольні суми EA CRC32; редагування Cash і Bounty.
- **Underground 2:** Original Xbox 20CM, три HMAC-SHA1; редагування Cash.
- **Carbon:** Original Xbox 20CM, стиснення JDLZ, три HMAC-SHA1; редагування Cash.
- Невідомі й пошкоджені формати відхиляються без сліпого редагування.
