# NFS Save Lab NX — v0.6

**Готово: новий стартовий екран із трьома піксельними постерами Most Wanted, Underground 2 та Carbon.** Обрана гра підсвічується неоновою рамкою, а назва й рік залишилися в компактній смузі знизу.

## Встановлення v0.6

**Треба розпакувати повний ZIP на корінь карти пам'яті** (через DBI чи комп'ютер), зберігаючи структуру:

```text
sdmc:/switch/nfs_save_lab_nx.nro
sdmc:/switch/NFS_Save_Lab_NX/posters/mw.rgb
sdmc:/switch/NFS_Save_Lab_NX/posters/u2.rgb
sdmc:/switch/NFS_Save_Lab_NX/posters/cx.rgb
```

Увага: у цій збірці постери **зовнішні файли**, а не частина `.nro`. Просто один `.nro` запуститься, але покаже повідомлення **ART PACK MISSING** замість ілюстрацій. Папка з постерами необхідна лише для нового оформлення, на сейви не впливає.

Керування: `L/R` — змінити гру, `A` — відкрити її сейви, `B` — назад, `+` — вихід із головного меню.

## Редагування збережень

**Most Wanted (Xbox 360): Edit Cash (MC02)** уже використовує алгоритм, успішно перевірений користувачем на консолі, із перерахунком MD5 і трьох CRC EA, перевіркою оригіналу та створенням резервної копії `.nfslab.bakN`. Суму вибираєш сам від 0 до 999 999 999. Обов'язково тримай незалежну копію всієї кар'єри й редагуй лише після повного виходу з гри.

**Bounty (“рейтинг” за погоні) та Heat поки НЕ редагуються.** Для безпечної реалізації потрібен другий сейв із точно відомим зміненим Bounty. Після цього зможемо перевірити поле й перевести його на той самий контрольний механізм. Underground 2 і Carbon зараз підтримуються лише в режимі пошуку/аналізу.
