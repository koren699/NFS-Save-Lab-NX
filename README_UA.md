# NFS Save Lab NX — experimental Switch homebrew v0.1

**Стан:** вихідний код, збирання за допомогою devkitA64/libnx та GitHub Actions. Інструмент не перевірено на фізичній консолі або реальних сейвах NFS. Не використовуйте на єдиній копії прогресу!

## Порти, які скануємо

- **Most Wanted (2005), Xbox 360** — порт [StevensND/nfsmw-nx](https://github.com/StevensND/nfsmw-nx). Перевіряємо `/switch/nfsmw-nx/nfsmw/` та `/switch/nfsmw/nfsmw/`. Також показуємо backup-папки `saves/`, але **блокуємо запис** до цих копій.
- **Underground 2, Xbox Original** — [antoxa2584x/nfsu2-sw](https://github.com/antoxa2584x/nfsu2-sw), `/switch/nfsu2x/game/UDATA/`.
- **Carbon, Xbox Original** — [antoxa2584x/nfsc-sw](https://github.com/antoxa2584x/nfsc-sw), `/switch/nfscx/game/UDATA/`.

Шляхи залежать від конкретного пакету та розміщення гри. Відсутність файлів не означає відсутності сейвів.

## Можливості

1. Шукає файли у вкладених папках трьох портів.
2. За поточним значенням Cash/Bounty знаходить рівні йому чотирибайтові цілі числа у форматі big-endian / little-endian.
3. Дозволяє вибрати зсув і нове значення.
4. Створює резервну копію оригіналу із суфіксом `.nfslab.bakN`, а потім змінює вибрані 4 байти. При помилці заміни намагається відкотити файл.
5. Блокує редагування резервних копій MW.

**Увага:** редактор не визначає напевно поле Cash/Bounty, не обробляє зашифровані чи стиснені поля та не перераховує внутрішні контрольні суми EA/Xbox. Тому гра може відмовитися відкривати модифіковане збереження. Пошук збігу байтів не підтверджує, що це гроші.

## Керування

- Головне меню: `L/R` — гра; `A` — сканувати папки; `+` — вихід.
- Список: `↑/↓` — файл; `A` — вибрати; `B` — назад.
- Сума: `←/→` — розряд; `↑/↓` — змінити; `A` — пошук.
- Збіги: `↑/↓` — зсув; `A` — перейти до нової суми.
- Запис: утримуйте `ZL+ZR` і натисніть `A` для підтвердження.

Перед роботою повністю завершіть гру. Для тестування створіть окремий профіль, скопіюйте його сейв і переконайтесь, що маєте змогу відновити оригінал.

## Як отримати NRO з GitHub

1. Відкрийте вкладку **Actions** у цьому репозиторії.
2. Виберіть **Build Nintendo Switch NRO**, потім **Run workflow**, якщо збірка ще не стартувала.
3. Після зеленого статусу відкрийте run → **Artifacts** → **NFS-Save-Lab-NX**.
4. Розпакуйте ZIP, скопіюйте `nfs_save_lab_nx.nro` до `/switch/NFS_Save_Lab_NX/` на microSD, відкрийте HBMenu.

Конфігурація використовує Docker `devkitpro/devkita64:latest`. Для самостійної збірки — `make -j4` із `DEVKITPRO`, `DEVKITA64` та devkitPro у PATH.

## Перевірка рушія

```sh
bash tests/run.sh
```

Тести перевіряють пошук LE/BE у штучних файлах, зміну значення та збереження попереднього файлу. **Вони не перевіряють коректність ігрового формату.**

## План наступної версії

Потрібні тестові сейви всіх трьох ігор, щоб визначити реальний формат балансу та валідацію даних. Поки це діагностичний, а не гарантовано робочий редактор.
