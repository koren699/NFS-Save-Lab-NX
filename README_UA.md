# NFS Save Lab NX v0.8 — високоякісні постери

У v0.7 постери були зменшені до **80×100 / 32 кольори** і розтягнуті до розміру карток. На Switch через це вони виглядали розмитими та занадто зернистими.

У v0.8 графічний рушій підтримує **336×360 / RGB565 (до 65 536 кольорів)**. Зображення в цій якості можна додати безпосередньо до **одного** `.nro`, без папки `posters` на microSD.

## Важливо щодо пакетування

Звичайна автоматична збірка GitHub Actions компілює ядро програми **без HD-ресурсів** і за відсутності додатка використовує старі вбудовані 80×100 постери. Щоб отримати **повну v0.8 HD**, потрібен уже готовий `.nro` із доданим спеціальним кінцевим пакетом RGB565. Такий готовий файл надано окремо у чаті користувачеві.

Нативний читач у `source/main.c` перевіряє завершальний заголовок `NFSLABP8` (версія 1, 336×360, довжина 725 760 байтів) і читає ресурси без змін сейвів. Він шукає файл за `argv[0]` або стандартним шляхом `sdmc:/switch/nfs_save_lab_nx.nro`. Якщо даних немає — показує зображення v0.7.

Для відтворення повної збірки використовується `tools/append_hd_posters.py`, якому потрібні три **336×360 RGB565 little-endian** постери (піксельні ілюстрації власника) та базовий NRO. Постери не додавалися до публічного репозиторію. **Додавання окремого блоку зображень до NRO ще не тестувалося на фізичному Switch**, тому якщо HBMenu не запустить нову версію, поверни робочу v0.7 і повідом про помилку.

## Функції сейвів

Алгоритм **Cash Edit (MC02)** з v0.5 збережено без змін. У користувача він уже успішно працював на фізичному Switch. Перед редагуванням закривай гру й зберігай незалежну копію сейву. Bounty Info читає рейтинг, але редагування рейтингу ще заблоковане, доки не буде підтверджено завантаження спеціально зміненої копії. Heat — лише діагностика.

## Встановлення

Поклади **готовий HD NRO** у `sdmc:/switch/nfs_save_lab_nx.nro` із заміною попередньої версії. Окремої папки постерів більше не потрібно. Використовуй Homebrew Menu.
