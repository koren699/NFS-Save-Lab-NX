# NFS Save Lab NX v0.9 — Edit Bounty + HD постери

**Новий підтверджений тест v0.9:** користувач продав попередній автомобіль, придбав три нові, у редакторі встановив загальний Bounty **200 000**, після чого Most Wanted успішно завантажила сейв і показала правильний рейтинг. Це підтверджує редагування після продажу та за кількох активних автомобілів у перевіреній кар'єрі. Сумісність з усіма можливими профілями не гарантується — незалежні резервні копії залишаються обов'язковими.

**Нова можливість:** редагування загального рейтингу (Bounty) для Xbox 360-порту Most Wanted 2005. Алгоритм протестовано на справжньому сейві користувача: змінений файл із рейтингом **100 000** успішно завантажився у грі. Нова реалізація, що працює безпосередньо в програмі, має автоматичні тести, але її ще потрібно перевірити на самій консолі.

## Як працює рейтинг

У сейві MC02 зберігається:
- **Sold history:** загальний Bounty автомобілів, які раніше були продані; адреса `0xE86D`, u32 Big Endian.
- **Активні машини:** записи у таблиці `0xE2F5`, 25 позицій із кроком `0x38`; Bounty кожної за `+0x10`, u32 Big Endian.
- **Неактивний слот** має байт `0xFF` на початку. У ньому можуть залишитися старі значення Bounty; такі записи НЕ враховуються.
- Загальна сума = `Sold history + сума Bounty активних машин`.

Програма зчитує всі 25 слотів, перевіряє їхню структуру, відкидає порожні, знаходить суму з історії продажів. У меню **EDIT BOUNTY (MC02)** можна самостійно задати нове загальне значення 0–999 999 999.

Якщо в гаражі кілька автомобілів, **L/R** перемикають, у якому саме активному автомобілі буде скориговано Bounty. За замовчуванням намагається вибрати поточне активне авто за вказівником `car_number`. Усі інші машини й історія продажів залишаються недоторканими.

**Обмеження безпеки:** не можна зменшити рейтинг нижче суми **історичного рейтингу та рейтингу всіх інших активних машин**, оскільки це вимагало б змінювати історію продажів чи інші машини. Якщо структура сейву невідома, запис заблокований. Редагування Bounty в Underground 2 / Carbon не підтримується.

## Встановлення

Повний v0.9 HD-дистрибутив надано у чаті. Скопіюй `nfs_save_lab_nx.nro` у `sdmc:/switch/`. Високоякісні постери **336×360, RGB565** вбудовано в один готовий NRO; папки з окремими картинками не потрібні.

**Важливо:** GitHub Actions збирає базовий NRO зі старими 80×100 постерами. У повному HD-пакеті використовується додатковий блок графічних ресурсів усередині NRO. Його додають після збірки.

## Як користуватися

1. Зроби **незалежну копію активного сейву**, а не лише автоматичний backup нашої програми.
2. Повністю закрий Most Wanted, запусти homebrew.
3. Вибери **MOST WANTED → [LIVE] KOREN69 → EDIT BOUNTY (MC02)**.
4. Побачиш нинішній загальний Bounty, історію проданих машин і кількість активних. Виставляй нову суму стрілками.
5. Якщо машин кілька, **L/R** обирають активний слот, де відбудеться зміна; на екрані показано **мінімально допустимий загальний Bounty** для вибраного авто.
6. Натисни **A** для перевірки, а потім тримай **ZL + ZR** і натисни **A**, щоб підтвердити запис.

Перед записом програма перевіряє `MC02` із **точним розміром 62 688 байтів**, поточну суму, структуру гаража, MD5 і три CRC32 EA. Створює `.nfslab.bakN`, формує змінений файл, перераховує суми та ще раз перевіряє результат.

**Грошовий редактор Edit Cash** залишився як раніше, на успішно перевіреному алгоритмі. **Heat** — тільки читання.

## Попередження

Хоча алгоритм зміни Bounty перевірено успішним завантаженням тестової кар'єри, **універсальний механізм після майбутніх покупок/продажів або за кількох активних машин ще не перевірений у грі**. Він пройшов тести на штучних сейвах, але першу спробу після зміни автомобіля проводь лише з незалежною резервною копією. Не запускай редактор, поки гра працює.
