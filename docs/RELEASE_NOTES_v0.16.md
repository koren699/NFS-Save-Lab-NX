# NFS Save Lab NX v0.16 — Most Wanted / Underground 2 / Carbon

## 🇺🇦 Українська

**NFS Save Lab NX** — неофіційна homebrew-програма для Nintendo Switch, яка дозволяє редагувати збереження фанатських портів **Need for Speed: Most Wanted (2005), Underground 2 та Carbon**.

**Можливості v0.16:**
- **Most Wanted (2005):** зміна кількості грошей (**Cash**) і накопиченого рейтингу поліції (**Bounty**). Редактор правильно враховує активні автомобілі та історію проданих машин.
- **Underground 2:** встановлення довільної суми грошей (**Cash**).
- **Carbon:** встановлення довільної суми грошей (**Cash**).
- Автоматичний пошук підтримуваних файлів кар’єри та перевірка цілісності збережень.
- Перевірені резервні копії `.nfslab.bakN` перед записом; перевірка зміненого файла.
- Піксельний інтерфейс із трьома HD-постерами та власною іконкою Homebrew Menu.

**Усі перелічені функції протестовані на реальній Nintendo Switch.** Підтримуються відповідні фанатські Switch-порти, а не PC-версії ігор.

**Встановлення:** завантажте **Full HD NRO** з вкладень до цього релізу, скопіюйте `nfs_save_lab_nx.nro` у `sdmc:/switch/`, запустіть через Homebrew Menu. Повністю закрийте гру й зробіть незалежну копію папки збережень. Виберіть гру, файл кар’єри та бажану суму. Підтвердження запису — **ZL + ZR + A**.

## 🇬🇧 English

**NFS Save Lab NX** is an unofficial Nintendo Switch homebrew save editor for the community ports of **Need for Speed: Most Wanted (2005), Underground 2, and Carbon**.

**What's included in v0.16:**
- **Most Wanted (2005):** edit **Cash** and accumulated police **Bounty**, correctly accounting for current garage cars and sold-car bounty history.
- **Underground 2:** set a custom **Cash** amount.
- **Carbon:** set a custom **Cash** amount.
- Automatic detection and integrity checking of supported career saves.
- Verified `.nfslab.bakN` backups before editing, followed by save validation.
- Retro pixel-art interface featuring three HD game posters and a custom Homebrew Menu icon.

**All listed editing features have been tested on a real Nintendo Switch.** This utility supports the specific fan-made Switch ports, **not the PC versions** of the games.

**Installation:** download the **Full HD NRO** attached to this release, copy `nfs_save_lab_nx.nro` to `sdmc:/switch/`, and run it through Homebrew Menu. Completely close the game and back up the entire save folder independently first. Select the game and career, enter the desired value, then confirm the write with **ZL + ZR + A**.

## 🇷🇺 Русский

**NFS Save Lab NX** — неофициальный homebrew-редактор сохранений для Nintendo Switch и фанатских портов **Need for Speed: Most Wanted (2005), Underground 2 и Carbon**.

**Возможности v0.16:**
- **Most Wanted (2005):** редактирование денег (**Cash**) и накопленного рейтинга полиции (**Bounty**) с учётом автомобилей в гараже и истории проданных машин.
- **Underground 2:** изменение количества денег (**Cash**).
- **Carbon:** изменение количества денег (**Cash**).
- Автоматический поиск и проверка поддерживаемых файлов карьеры.
- Проверенные резервные копии `.nfslab.bakN` перед изменением сохранения и повторная проверка после записи.
- Пиксельный интерфейс с тремя HD-постерами и собственной иконкой Homebrew Menu.

**Все перечисленные функции протестированы на реальной Nintendo Switch.** Программа создана для конкретных фанатских портов Switch, **не для PC-версий игр**.

**Установка:** скачайте **Full HD NRO**, прикреплённый к этому релизу, скопируйте `nfs_save_lab_nx.nro` в `sdmc:/switch/` и запустите через Homebrew Menu. Полностью закройте игру и заранее сделайте независимую резервную копию всей папки сохранения. Выберите игру, карьеру и нужную сумму. Для подтверждения записи удерживайте **ZL + ZR + A**.
