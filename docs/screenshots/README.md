**To add these:** Open [Upload files to this directory](https://github.com/koren699/NFS-Save-Lab-NX/upload/main/docs/screenshots), select all four named JPEG images from the release kit, and commit directly to `main`. After commit, the public GitHub Release images will resolve using URLs under `https://raw.githubusercontent.com/koren699/NFS-Save-Lab-NX/main/docs/screenshots/`.

Do not upload game saves, certificates, or other personal data; screenshots only. All screenshots were provided by the project developer for this publication.
