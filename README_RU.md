# NFS Save Lab NX — редактор сохранений для Nintendo Switch

**Актуальная версия: v0.16.** Homebrew-приложение для редактирования сохранений фанатских портов **Need for Speed: Most Wanted (2005), Underground 2 и Carbon** на Nintendo Switch.

[🇺🇦 Українська](README_UA.md) · [🇬🇧 English](README.md) · [🇷🇺 Русский](README_RU.md)

## Возможности

| Игра | Деньги (Cash) | Рейтинг (Bounty) |
|---|---|---|
| **Most Wanted (2005)** | ✅ | ✅ |
| **Underground 2** | ✅ | — |
| **Carbon** | ✅ | — |

- Устанавливайте **произвольную сумму денег** в каждой из трёх игр.
- В **Most Wanted** редактируйте накопленный Bounty с учётом активных машин и истории проданных автомобилей. Если автомобилей несколько, выберите нужный кнопками **L/R**.
- Автоматическое обнаружение файлов карьеры, проверка формата и защитных подписей.
- **Проверенная резервная копия `.nfslab.bakN` перед каждым изменением**, повторная проверка после записи и предусмотренное восстановление.
- В полном HD-выпуске — три качественных пиксельных постера и собственная пиксельная иконка для Homebrew Menu.

**Перечисленные функции проверены в игре на Nintendo Switch.** Совместимость со всеми будущими версиями портов или изменёнными сохранениями не гарантируется. Приложение разработано для конкретных фанатских **Switch-портов, не для ПК-версий**.

## Скачать

Откройте **[GitHub Releases](https://github.com/koren699/NFS-Save-Lab-NX/releases)** и после публикации первого выпуска скачайте **`nfs_save_lab_nx.nro` (Full HD)** или ZIP с приложением.

> Полная сборка **Full HD** содержит пиксельные постеры и фирменную иконку. Обычная автоматическая сборка GitHub Actions может содержать упрощённые изображения.

## Установка и использование

1. Поместите `nfs_save_lab_nx.nro` в `sdmc:/switch/` на microSD.
2. **Полностью закройте игру.** Перед первым изменением скопируйте **всю папку сохранения** в безопасное место вне активной папки игры.
3. Откройте Homebrew Menu, запустите **NFS Save Lab NX** и выберите постер нужной игры.
4. Выберите файл карьеры (если их несколько) и функцию **Edit Cash** либо **Edit Bounty** в Most Wanted.
5. Стрелками выберите желаемую сумму, нажмите **A**.
6. Для подтверждения удерживайте **ZL + ZR** и нажмите **A**.
7. Откройте игру и проверьте результат. Не удаляйте независимую резервную копию, пока не убедитесь, что сохранение загружается.

## Технические подробности

- **Most Wanted:** Xbox 360 MC02, MD5 и EA CRC32; редактирование Cash и Bounty.
- **Underground 2:** Original Xbox 20CM, три HMAC-SHA1; редактирование Cash.
- **Carbon:** Original Xbox 20CM, сжатие JDLZ, три HMAC-SHA1; редактирование Cash.
- Неизвестные или повреждённые сохранения не изменяются вслепую.
